# DM Tools 🧙

This repository is a set of tools to help me with Dungeon Mastering DnD games, partially inspired by the great [Legend Keeper](https://www.legendkeeper.com/).

For now here is a list of the tools provided :

- 🗺️ Custom Maps from Hi-Res images

## Getting started

The entire project is Dockerized 🐋, running this command should be the only task you have to do to run it locally :

```bash
docker compose up -d
```

-> You can then visit [localhost:3000](localhost:3000) to access the Front-end server.

💌 If you find any bug or problems, please create an issue in the repository.
